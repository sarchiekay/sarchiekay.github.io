# Sarah Kwenda — Product Owner Portfolio

Personal portfolio site for Sarah Kwenda, Product Owner specialising in fintech, consumer credit, digital wallets, and payments for emerging markets.

**Live:** https://sarahkwenda.com

## About

This is a static HTML portfolio built with semantic HTML, vanilla CSS, and no dependencies. It showcases 10+ years of product ownership across startups, regulated fintech, and enterprise SaaS.

## Sections

- **Who I Am** — My story and background
- **What I Do** — Core services and delivery approach
- **My Work** — 5 selected case studies
- **Where I've Been** — Timeline of roles and experience
- **Credentials** — Certifications and domain expertise
- **How I Work** — AI-augmented delivery and current focus
- **Let's Connect** — Contact and opportunities

## Tech

- Pure HTML + CSS (no build process, no dependencies)
- Responsive design (mobile-first)
- Semantic HTML for accessibility
- Zero JavaScript (except smooth scroll via browser)

## Local Development

```bash
npx serve .
```

Serves on `localhost:3000`. Changes are live.

## Deployment

This site is deployed via GitHub Pages. Push to `main` and it auto-deploys within 30 seconds.

```bash
git push origin main
```

## Custom Domain

The site points to `sarahkwenda.com` via DNS. To update:

1. Buy domain on Namecheap/Google Domains
2. Point nameservers to GitHub Pages: `cname.github.com`
3. Add CNAME record in GitHub repo root (or Pages settings)
